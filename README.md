# 📚 EduSpin

EduSpin is a modern Android quiz application focused on:

- ⚛️ Spintronics
- 🧲 Solid State Physics
- 🔬 Semiconductor Physics
- 📖 Quantum Mechanics

---

## 🚀 Features

- 📝 10 Physics Quiz Topics
- 📚 JSON-based References System
- 🤖 AI Chat Integration
- 📱 Clean RecyclerView UI
- 🎨 Modern Android Design

---

## 🛠 Built With

- Java
- Android Studio
- JSON
- RecyclerView
- OpenAI API
